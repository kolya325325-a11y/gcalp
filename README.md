# Калькулятор

Портативный калькулятор для Windows и macOS с интерфейсом на Tkinter. Для запуска из исходников нужны Python 3.10 или новее и Tkinter; сторонние библиотеки приложению не требуются.

Операции выполняются с обычным математическим приоритетом: сначала скобки, затем умножение и деление, после них сложение и вычитание. Скобки можно вводить кнопками или с клавиатуры. Незакрытые скобки при нажатии `=`, лишняя закрывающая скобка и пустые скобки считаются ошибкой; для сброса нажмите `C` или `Esc`. Между числом и открывающей скобкой подразумевается умножение.

Кнопка `☰` в левом верхнем углу открывает переключатель режимов. В режиме «Инженерный» доступны стандартные операции и дополнительные функции: `sin`, `cos`, `tan`, обратные тригонометрические функции, `ln`, `log`, `eˣ`, `10ˣ`, квадрат, куб, корень, обратное число, модуль, факториал и константы `π` и `e`. Кнопка `DEG` переключает тригонометрические функции между градусами и радианами.

В режиме «Графический» можно вводить несколько функций от `x`, например `sin(x)`, `x^2`, `sqrt(x)` или `cos(x)+5`. Кнопка «+ Добавить график» добавляет новую строку, а кнопка `×` удаляет её. Панель быстрых кнопок вставляет цифры, функции, `x`, скобки и арифметические операторы в выбранную строку. Кнопка «Построить» рисует все функции на координатной плоскости разными цветами; масштаб изменяется кнопками `+` и `−` или колёсиком мыши, а вид можно перемещать перетаскиванием.

## Запуск из исходников

Из папки проекта выполните:

```powershell
python calculator.py
```

## Сборка в `.exe` (Windows)

Сборку нужно выполнять в Windows на компьютере с Python 3.10+ и Tkinter. PyInstaller собирает приложение для текущей операционной системы и не предназначен для кросс-сборки Windows-приложений из другой ОС.

В PowerShell из папки проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean Calculator.spec
.\.venv\Scripts\python.exe check_packaged_icons.py -v
```

Готовый файл появится здесь:

```text
dist\Calculator.exe
```

Файл `Calculator.spec` собирает программу в один исполняемый файл без консольного окна и добавляет весёлую иконку калькулятора в `.exe` и на панель задач. PyInstaller нужен только для сборки и не является зависимостью запускаемого приложения.

Иконка встраивается во время сборки: уже существующие копии `.exe` не обновляются автоматически. После пересборки замените старый файл на рабочем столе или в другой папке новым `dist\Calculator.exe`. Если Проводник ещё показывает прежний значок, обновите окно клавишей `F5`.

## Сборка в `.app` (macOS)

Сборку нужно выполнять на Mac с Python 3.10+ и Tkinter. Убедитесь, что Python установлен (например, через Homebrew или официальный установщик).

Из папки проекта выполните в Terminal:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install pyinstaller
python -m PyInstaller --noconfirm --clean Calculator.spec
python check_packaged_icons.py -v
```

Готовое приложение появится здесь:

```text
dist/Calculator.app
```

Запустить его можно двойным кликом или из Terminal:

```bash
open dist/Calculator.app
```

На macOS для кнопок используется тема Tk `clam`, позволяющая задавать цвета фона и текста. Меню переключения режимов использует системные цвета.

Файл `.app` получает ту же иконку, что и версия для Windows. Исходный PNG, ICO для Windows и ICNS для macOS находятся в папке `assets`; для пересборки достаточно запустить `Calculator.spec` на нужной системе. Скрипт `check_packaged_icons.py` проверяет значок непосредственно в собранном `.exe` или `.app`.

После пересборки замените старую копию `Calculator.app` новым приложением из `dist`: иконка уже существующей копии сама не изменится.
